# Battle catalog and contemporary Kanto learnsets

The catalog is generated from pinned source data, not hand-written move lists.
`Assets/AeroStadium/Resources/Data/catalog.json` keeps the existing 151 Kanto
species and adds the canonical main-series move and item catalogs. Species
names, base stats, colors, types, and display heights are preserved exactly.
Move IDs remain the National move IDs already used by the old catalog. The
existing `lifeorb`, `leftovers`, `charcoal`, and `none` item IDs remain compatible.

## Learnset policy

Each base Kanto Pokémon gets the union of ordinary moves legitimately available
to that species in Scarlet/Violet including both DLCs and Légendes Z-A including
Mega Dimension. A level-up, TM, egg, tutor, or contemporary event source counts;
the acquisition method does not restrict team building. Only generation-9
sources from the corresponding game's table count. Historical transfers from
earlier generations are not automatically imported.

Pre-evolution chains are traversed within each selected game. This includes
non-Kanto babies such as Pichu, Cleffa, Igglybuff, Tyrogue, Mime Jr., Smoochum,
Elekid, and Magby. The importer never traverses regional-form or Mega-form
learnsets to supply the ordinary Kanto form.

99 species have Scarlet/Violet sources and 65 have Z-A sources, covering 123
distinct Kanto species. For the remaining 28, Champions is checked first; it
adds no missing species at the pinned revision. Six use their later Légendes
Arceus ordinary learnsets and 22 use Brilliant Diamond/Shining Pearl. Sword and
Shield is a final fallback if no newer source exists. The actual game is written
in each species' `learnsetVersion`; fallbacks are not presented as SV data.

`learnableMoves` is the sorted, unique legal list. `moves` contains at most four
legal defaults. The file `learnset-evidence.json` records the source game,
source Pokémon, method/source codes, and pre-evolution inheritance for every
species–move link. For example, `9L15` denotes level 15 in generation 9 and `9M`
denotes a generation-9 machine source. Ditto's ordinary learnset is only
Transform; Struggle is generated by combat and is not a selectable taught move.

Z-A Plus variants and Arceus Agile/Strong styles are not separate moves. Existing
Z/Max powered moves remain in the historical catalog, marked
`powered-variant`, and never appear in ordinary learnsets. The 18 Colosseum/XD
Shadow moves are excluded because their Shadow type is outside the normal
main-series type catalog. This is not a roster of every move in every spin-off.

## Move and item data

919 canonical main-series moves are imported. Ordinary turn-based type,
physical/special/status category, power, accuracy, PP, and priority use current
Showdown metadata when available, with PokéAPI as the fallback. Z-A cooldowns
are not converted into PP. Accuracy zero means an accuracy check is bypassed.
French names and descriptions come from PokéAPI's French localization tables.

Items retain canonical slugs and PokéAPI numeric `dexId` references. The source
contains 2,223 item records rather than every integer ID through 2,279. The
project excludes 92 Mega Stones and 71 Z-Crystal records, leaving 2,060 actual
items plus the `none` sentinel. Exclusion includes the 35 held and 35 bag
Z-Crystal records and Ilima's Normalium Z. Some bag crystals belong to the
upstream `unused` category, so source mechanic flags are checked as well as
categories. Future imports apply the same policy. The local `excluded-items.json`
records every removed source ID and name. Generic type gems, Primal Orbs, and
Mega-related accessories remain because they are not Mega Stones or Z-Crystals.
The source also contains Roseli Berry twice; both remaining source records are preserved with unique
internal IDs. A French localization is reused from the first record. Baie Hopo
uses its ordinary French name where the latest row is untranslated. The unused
God Stone retains an English fallback label and is never a held-item option.

Key items, balls, machines, ingredients, and other non-held items belong to the
catalog but are not offered as Pokémon equipment. Sparse upstream holdable
flags are supplemented with Showdown's held-item records. Availability and
implementation are distinct: an existing item can still require a mechanic
that the current combat engine does not support.

`mechanics.support` (moves) and `support` (items) are explicit:

- `implemented`: the imported ordinary mechanics are supported by this engine;
- `partial`: basic behavior is usable, but additional rules remain unfinished;
- `unsupported`: cataloged for completeness, with no claim of faithful behavior.

The importer does not claim that all 919 moves or all item effects are fully
implemented. Complex weather, terrain, hazards, charge/recharge, counter,
conditional power, abilities, and similar behaviors are flagged rather than
silently represented as ordinary complete moves. Full numerical source and
support audits remain available locally. No animation assets are imported.

## Reproduce

```powershell
python .\Tools\import_battle_catalog.py --repo . --apply
```

This downloads only the pinned public source tables, validates the complete
catalog, saves the previous catalog once, and then installs the JSON. To repeat
using the existing cache:

```powershell
python .\Tools\import_battle_catalog.py --repo . --apply --offline
```

Validation checks all 151 species, sorted/unique legal lists, the four-move
default limit, complete move references, evidence for every learnset entry,
powered-move exclusion, unique item IDs, Ditto's one legal move, and the
physical/special distinction between Flame Charge and Flamethrower.
